# Self-Improving RAG Platform Frontend

## Quick Start

To run the Self-Improving AI Context Engineering Platform frontend:

### 1. Install Dependencies

```bash
npm install
```

### 2. Start the Development Server

```bash
npm start
```

The application will open in your browser at `http://localhost:3000`

## Features

This frontend demonstrates the complete Self-Improving AI Context Engineering Platform including:

- **Dashboard**: Real-time performance metrics with uncertainty visualization
- **Token Betting**: Gamified optimization system where you can bet tokens on improvements
- **MCP Servers**: Management interface for MCP server monitoring and health
- **Context Builds**: Advanced context management with causal analysis
- **API Usage**: Analytics for API performance and cost tracking
- **Data Sources**: Company data integration monitoring
- **Self-Improvement**: Real-time view of automated learning and improvements
- **Achievements**: Gamified progression system
- **Leaderboards**: Team competition and rankings

## Key Interactive Features

- Toggle uncertainty visualization (Sigma button in header)
- Place token bets on optimization outcomes
- Monitor MCP server health in real-time
- View causal impact analysis for context elements
- Track API usage and cost savings
- Observe self-improvement events as they happen

## Architecture

The frontend is built with:
- React 18 with TypeScript
- Recharts for data visualization
- Lucide React for icons
- Tailwind CSS for styling
- Mock data demonstrating real-world scenarios

## Technologies

- **Frontend**: React + TypeScript
- **Visualization**: Recharts (charts, graphs, radar plots)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Build**: React Scripts

This is a demonstration frontend that showcases how the Self-Improving RAG Platform would look and feel in production, with all the statistical rigor, gamification, and MCP integration features.
